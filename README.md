# Project Portfolio

This repository serves as a central hub for my analytical and machine learning projects, developed as part of my MSc in Financial Data Analytics at LUMSA University and independent research. Each project demonstrates the use of statistical modeling, data analysis, and computational methods applied to real-world data.

---

## Projects

### 1. Analysis of Productivity for Garment Factory Workers
**Repository:** [Garment Worker Productivity](https://github.com/l-vice/Garment_Productivity)  
**Overview:** Applied Logistic Regression, LDA, QDA, and Regularized Classifiers to analyze factors influencing worker productivity in Bangladeshi garment factories. The study focused on feature selection, model evaluation, and operational efficiency measurement using cross-validation and confusion-matrix diagnostics.  
**Report:** [View HTML Report](https://l-vice.github.io/Garment_Productivity/analysis_summary_R.html)

---

### 2. Hidden Markov Models for Algorithmic Trading
**Repository:** [HMM for Algorithmic Trading](https://github.com/l-vice/HMM_FX)  
**Overview:** Developed Hidden Markov and Hidden Semi-Markov Models to identify latent regime shifts in EUR-based FX markets. Compared Normal and Student-t emission distributions under Poisson and Gamma sojourn structures. Evaluated model fit using AIC, BIC, and ICL to interpret volatility regimes.  
**Report:** [View HTML Report](https://l-vice.github.io/HMM_FX/analysis_summary_R.html)

---

### 3. Prediction of Engagement Metrics – Louis Rossmann YouTube Channel
**Repository:** [YouTube Engagement Prediction](https://github.com/l-vice/YouTube_Engagement)  
**Overview:** Modeled YouTube like-to-view ratios using Random Forest, XGBoost, and AdaBoost regressors. Applied feature engineering to capture interaction metrics, video duration, and audience engagement patterns. The analysis was replicated in both R and Orange3 to evaluate model interpretability and predictive power.  
**Report:** [View HTML Report](https://l-vice.github.io/YouTube_Engagement/analysis_summary_R.html)

---

### 4. Regression Modeling – Hurdle and GAMLSS Frameworks
**Repository:** [Hurdle & GAMLSS Modeling](https://github.com/l-vice/Hurdle_Model)  
**Overview:** Modeled zero-inflated and heteroskedastic data using Hurdle and GAMLSS models with Logarithmic and Weighted Least Squares distributions. Compared transformations and weighting schemes to improve distributional fit, model stability, and residual diagnostics.  
**Report:** [View HTML Report](https://l-vice.github.io/Hurdle_Model/analysis_summary_R.html)
