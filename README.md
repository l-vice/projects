Project Portfolio

This repository serves as a central hub for my analytical and machine learning projects, developed as part of my MSc in Financial Data Analytics at LUMSA University and through independent research.  
Each project demonstrates applied statistical modeling, data analysis, and computational methods using real-world data.

---

## Projects

### 1. Regression Modeling – Hurdle and GAMLSS Frameworks
**Repository:** [regmod_hurdle](https://github.com/l-vice/regmod_hurdle)  
**Overview:** Developed Hurdle and GAMLSS models to handle zero-inflated and heteroskedastic data. Implemented logarithmic and weighted least squares formulations to improve distributional fit and residual stability. Evaluated model performance using diagnostic plots and distributional comparisons.  
**Report:** [View HTML Report](https://github.com/l-vice/regmod_hurdle/blob/main/09092025_hurdle_model_report_LBK.html)

---

### 2. Prediction of Engagement Metrics – Louis Rossmann YouTube Channel
**Repository:** [lr_yt_pred](https://github.com/l-vice/lr_yt_pred)  
**Overview:** Predicted the like-to-view ratio of YouTube videos using Random Forest, XGBoost, and AdaBoost regressors. Applied feature engineering to capture engagement metrics, duration, and timing effects. Analysis implemented in R and Orange3 with emphasis on interpretability and model validation.  
**Report:** [View HTML Report](https://github.com/l-vice/lr_yt_pred/blob/main/R/r_markdown/analysis_summary_R.html)

---

### 3. Hidden Markov Models for Algorithmic Trading
**Repository:** [hmm_fx](https://github.com/l-vice/hmm_fx)  
**Overview:** Implementation of Hidden Markov and Hidden Semi-Markov Models to identify latent regime shifts in EUR-based FX markets. Compared Normal and Student-t emissions under Poisson and Gamma sojourn structures. Evaluation and polishing in progress.  
**Report:** (Report link will be added after polishing and upload)

---

### 4. Analysis of Productivity for Garment Factory Workers
**Repository:** [garment_workers_productivity](https://github.com/l-vice/garment_workers_productivity)  
**Overview:** Applied Logistic Regression, LDA, QDA, and Regularized Classifiers to model productivity in Bangladeshi garment factories. Explored demographic and operational predictors of output efficiency using model diagnostics and cross-validation.  
**Report:** [View HTML Report](https://github.com/l-vice/garment_workers_productivity/blob/main/report/09102025_garment_workers_LBK.html)
